# 64-Bit RISC CPU in C

I was bored one weekend, so I threw this together; it's not really made for production.
When I first built it, I didn't intend to share it past my close friends, but after a lot of feature creep, it became a project worth sharing.

## Features

- CPU written in C for efficient execution
- Compiler written in Python for simple compilation of assembly-like code
- Custom ISA
